# MOTION DETECTION ALERTER

## PROJECT DESCRIPTION
This project is a motion detection alert system developed using ESP32.
It uses a PIR sensor to detect human movement and provides an alert using an LED and buzzer.

## COMPONENTS USED
- ESP32 Microcontroller
- PIR Motion Sensor
- LED
- Buzzer
- Breadboard
- Jumper Wires

## SOFTWARE USED
- Arduino IDE
- Wokwi Simulation

## WORKING PRINCIPLE
The PIR sensor detects motion in the surrounding area.
When motion is detected, the ESP32 receives a HIGH signal and activates the LED and buzzer as an alert.
When no motion is detected, the LED and buzzer remain OFF.

## FEATURES
- Real-time motion detection
- Audio and visual alert
- Sensor-based security system
- Simple embedded system project


## APPLICATIONS
- Home security systems
- Intrusion detection
- Smart automation systems
- Safety monitoring
